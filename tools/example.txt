notepad mint
============

a plain text editor. no ai, no sign-in, no telemetry.

	todo

	#include <stdio.h>

	int main(void)
	{
		puts("hello, mint");
		return 0;
	}

unicode just works:  café  naïve  日本語のテキスト  Привет  αβγ  ✓

the status bar shows line and column, the number of lines,
the size in bytes, the line ending and the encoding.
