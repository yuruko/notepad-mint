notepad mint 1.7.1

- quotes (`"..."`, `'...'`, curly quotes), `backticks`, fenced code blocks, python triple quotes, line comments (`//`) and `/* ... */` comments are drawn in italics inline; character widths and the caret stay where they were, and a `#` heading line stays bold
- `#` never makes text italic (1.7.0 did after a space): lines starting with `#` are markdown headings and stay bold
- the default editor font size is 10.5 pt (a saved size is kept)
- the status bar shows the selected font size (`10.5 pt`) next to the toggle buttons; click it to open the font dialog

**download**

- `notepad-mint-1.7.1-setup.exe`: installer and uninstaller
- `notepad-mint-1.7.1.exe`: standalone executable
- `SHA256SUMS.txt`: download checksums

settings remain in `%appdata%\notepad-mint\settings.ini`.
